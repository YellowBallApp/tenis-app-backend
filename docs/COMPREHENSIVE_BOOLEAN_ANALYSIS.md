## 💡 Key Insights

### Why Production Build Only?

1. **Debug Build:**
   - Type checking is lenient
   - JavaScript bridge is more forgiving
   - Implicit type conversions happen

2. **Production Build:**
   - Strict type checking
   - React Native Fabric enforces exact types
   - No implicit conversions
   - Boolean objects ≠ primitive booleans

### The Boolean() Constructor Problem

```typescript
Boolean(false) // Returns Boolean object (not primitive)
false          // Returns primitive boolean

typeof Boolean(false) // "object" ❌
typeof false          // "boolean" ✅
```

Native bridge expects primitive boolean, not Boolean object.
