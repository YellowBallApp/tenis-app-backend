# EGEV Tenis Kulübü - Mobile App UI/UX

A modern, premium tennis club management application with comprehensive features for court reservations, league management, challenges, and member interactions.

## 🎨 Design System

### Brand Colors
- **Primary Purple**: `#B4AEBD` - Used for accents, headers, and icons
- **Primary Green**: `#54CE8F` - Used for primary buttons, highlights, and success states
- **Background**: `#FAFCFB` - Soft white for backgrounds

### Design Principles
- Clean, premium and modern visual style
- Rounded components with soft shadows
- Generous spacing for easy touch interactions
- Hybrid Material + iOS inspired UI
- Tennis-themed iconography

## 🚀 User Flow Examples

### Book a Court
1. Tap "Courts" in bottom navigation
2. Browse available courts or use filters
3. Select a court to view details
4. Choose date and time slot
5. Review booking and payment details
6. Confirm reservation

### Challenge a Player
1. Tap "Create Challenge" on home screen
2. Search and select a player
3. Choose court and time
4. Add optional message
5. Send challenge
6. Wait for acceptance

### View League Standings
1. Tap "League" in bottom navigation
2. View current rankings
3. Check upcoming matches
4. Tap on a match for details
5. Enter results after playing

## 📐 Design Specifications

- **Mobile Frame**: 430px × 932px (iPhone 14 Pro Max size)
- **Border Radius**: Consistent rounded corners (12px - 24px)
- **Shadows**: Soft shadows for depth
- **Typography**: Clean sans-serif, optimized for readability
- **Touch Targets**: Minimum 44px height for buttons
- **Spacing**: 16px, 24px, 32px grid system
